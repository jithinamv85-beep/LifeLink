# LifeLink – Blood Donation & Emergency Donor Network

## 📌 About the Project

LifeLink is a web-based blood donation and emergency donor network designed to help patients find suitable blood donors quickly during emergency situations.

## 🎯 Problem

Finding a suitable blood donor during an emergency can be difficult and time-consuming.

LifeLink aims to make the process easier by connecting patients, donors, hospitals and administrators through a single platform.

## 🚀 Features

- 👤 Donor Registration
- 🔐 User Login & Logout
- 🩸 Blood Group Management
- 🚨 Emergency Blood Requests
- 🔎 Search for Blood Donors
- 📍 Nearby Donor Location
- 🔔 Notifications
- 🏥 Hospital Operations
- 📊 Admin Dashboard
- 📋 Donation History
